Developers have open access to Hiro's APIs without the use of an API key, but are subject to [Hiro's rate limit policy](/resources/guides/rate-limits). For developers who need access beyond these rate limits, we provide API keys.

:::callout
Sign in or create an account to [create and manage your API keys](https://platform.hiro.so) for free.

If you need even higher rate limits, please [contact us](mailto:support@hiro.so).
:::

## Manage your keys

In the [Hiro Platform](https://platform.hiro.so), you can create, copy, and revoke API keys.

1. Sign in or create an account.
2. Select **Create key**, enter a name and an optional description, then create the key.
3. Copy the key into your application's server-side configuration. You can reveal or copy it again later.

To stop using a key, select **Revoke**. Revoking a key permanently deletes it, so update any applications that use it first.

## Usage with cURL

The API key is passed in the `header` of your HTTP API request with `x-api-key`.

```terminal
$ curl https://api.hiro.so/... -H 'x-api-key: <your-api-key>'
```

## Usage with Node

This snippet shows how to perform a `fetch` request with your API key by including it in the request headers.

```ts fetch.ts
async function makeApiRequest(apiKey: string) {
  const url = `https://api.hiro.so/<your-api-endpoint>`;
  const response = await fetch(url, {
    headers: {
      "x-api-key": apiKey
    }
  });
  return response.json();
}
```

:::callout
type: warn
### Caution
The API key is passed in the header of your HTTP API request and is used only for private use, like in server-side applications.

If you use the API key in your client-side application, attackers can capture it using the client tools (E.g., browser console) and abuse your API key.
:::
